# The Edit — Modern Blog Platform

A responsive editorial blog landing page built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — all styling, responsive layouts, and visual artwork made with CSS
- `script.js` — topic filtering, live search, story preview dialog, mobile navigation, and newsletter demo interaction

## Run
Open `index.html` in a modern browser. No build tools or dependencies are required.
The Google Fonts import requires an internet connection; system fallbacks are included.

## Notes
The newsletter form is a front-end demo and does not send/store email addresses. Connect it to a backend or mailing-list service to make subscriptions real.
